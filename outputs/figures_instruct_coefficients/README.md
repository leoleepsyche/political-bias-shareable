# Instruct Model Stance/Coefficient Figures

Generated by `plot_instruct_stance_coefficients.py` from three instruct-model steering runs:

- `Qwen2.5-7B-Instruct`: `outputs/ideology_840_mps/run_840_mps_promptfixed_20260423_141925`
- `Mistral-7B-Instruct-v0.2`: `outputs/multimodel_840_batch_20260424_103114_pty/mistralai_Mistral_7B_Instruct_v0_2`
- `Llama-3-8B-Instruct`: `outputs/multimodel_840_batch_20260424_103114_pty/meta_llama_Meta_Llama_3_8B_Instruct`

Figure guide:

- `parse_rate_heatmap`: parsing reliability by model, language, side, and coefficient.
- `delta_mean_choice_by_coef`: dose-response curves, measured as mean stance-score change from `coef=0`.
- `stance_stacked_*`: stacked stance distributions across all coefficients for one model.
- `radar_coef4_*`: radar view of stance proportions at the strongest steering coefficient for one model.
- `radar_coef4_stance_proportions`: combined radar overview for all three models.
- `stance_distribution_long.csv`: aggregated source table used to create the figures.

Important caveat: Mistral has lower parse rates for some language settings, especially Italian and English, so its stacked bars include an `unparsed` segment and should be interpreted together with `parse_rate_heatmap`.
